# Contributing to Jackson 3 JSON Validation

First off, thanks for taking the time to contribute! 🎉

## How to Contribute

1.  **Fork the Repository**: Click the "Fork" button at the top right of this page.
2.  **Clone your Fork**: `git clone https://github.com/YOUR_USERNAME/jackson3-json-validation.git`
3.  **Create a Branch**: `git checkout -b feature/my-new-feature` or `git checkout -b fix/issue-number`
4.  **Make Changes**: Write your code and **add tests**.
5.  **Run Tests**: Ensure all tests pass with `mvn test`.
6.  **Commit**: `git commit -m "feat: add new validation logic"` (We prefer [Conventional Commits](https://www.conventionalcommits.org/)).
7.  **Push**: `git push origin feature/my-new-feature`
8.  **Open a Pull Request**: Go to the original repository and click "Compare & pull request".

## Development Setup

*   **JDK**: Java 17 or higher.
*   **Build Tool**: Maven 3.8+.
*   **IDE**: IntelliJ IDEA (recommended) or Eclipse/VS Code.

## Coding Standards

*   Follow standard Java naming conventions.
*   Keep dependencies minimal.
*   Write Javadoc for public methods.
*   **Always** include unit tests for new features or bug fixes.

## Reporting Bugs

Please use the [Bug Report Template](https://github.com/dogrulabs/jackson3-json-validation/issues/new?template=bug_report.md) when opening an issue. Include:
*   Library version.
*   Jackson version.
*   A minimal reproducible example.
